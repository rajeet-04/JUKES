# JUKE v2.1.0-beta Release Notes

## 🚀 Release Overview

**Release Date:** March 2, 2026  
**Version:** 2.1.0-beta  
**Status:** Beta Release  
**Milestone:** Security, Stability & UX Polish  

JUKE v2.1.0-beta brings hardened download security via a Cloudflare-managed API key, an automatic smart fallback between Spotdown and Spotmate, an improved update notification system, and a fully responsive player screen that adapts to any Android device size.

---

## ✨ What's New

### 🔐 Secure API Key Management (Cloudflare Worker)

- **Cloudflare KV Worker**: The Spotdown API key is no longer bundled in the APK. It is now fetched securely at runtime from a Cloudflare Worker backed by KV storage.
- **No More Hardcoded Secrets**: `SPOTDOWN_WORKER_URL` is injected via `local.properties` at build time — the actual key never ships in the binary.
- **Dynamic Key Rotation**: API keys can be rotated in the Cloudflare dashboard without needing an app update.
- **Referer Header**: All Spotdown requests now include a `Referer: https://spotdown.org/` header as required by the API.

### 🔄 Automatic Download Source Fallback

- **Spotdown → Spotmate Auto-Fallback**: If Spotdown fails (API error, network timeout, or duration mismatch > 10%), the app automatically retries the download using Spotmate without any user action.
- **Spotmate → Spotdown Vice-Versa**: If Spotmate was already the first attempt and fails, it falls back to Spotdown.
- **Duration Validation**: Post-download, the file is verified to match the expected track duration. If the mismatch exceeds 10%, it is discarded and the fallback source is used automatically.
- **Transparent UX**: Fallback happens silently in the background. Users always get their song.

### 🔔 Enhanced Update Notification Dialog

- **Emergency vs Normal Updates**: The app now distinguishes between normal feature updates and emergency/critical/hotfix releases.
  - 🔴 **Emergency** (keywords: `emergency`, `hotfix`, `critical` in tag or notes): Red themed dialog, cannot be dismissed without action.
  - ✅ **Normal**: Standard dialog with "Later" option.
- **Scrollable Changelog**: The release notes inside the dialog are now fully scrollable for long changelogs.
- **Redesigned Dialog**: Modern look with Surface containers, update icons, improved typography, and correct contrast against both light and dark dynamic color themes.

### 📱 Fully Responsive Player Screen

- **Screen-Adaptive Layout**: The player screen now uses `BoxWithConstraints` to measure the exact device height and scale all elements proportionally.
  - **Compact** devices (< 640dp height): Smaller spacers, reduced icon sizes, 38% artwork height
  - **Normal** devices (640–800dp): Balanced sizing, 42% artwork height  
  - **Large** devices / Tablets: Maximum sizes, 45% artwork height
- **Album Art Fix**: Artwork now uses `fillMaxHeight` + `aspectRatio(1f)` instead of `fillMaxWidth`, preventing overflow into controls on small phones.
- **Scaled Playback Controls**: Shuffle, prev/next, and play/pause buttons all scale with screen size.
- **Lyrics Overlay Fix**: Lyrics close button no longer misplaced due to incorrect `statusBarsPadding` inside the clipped artwork frame.
- **Adaptive Typography**: Track title and artist name font sizes reduce on compact screens.
- **Scaled Bottom Actions**: Queue, Radio, and Share icons scale down on small phones.

### 🏠 HomeScreen Layout Fix

- **Settings Button Always Visible**: Fixed a long-standing layout bug where long greeting text (e.g., "Night Vibes! Monday Tunes") would wrap and push the settings ⚙️ button off-screen. Applied `Modifier.weight(1f)` to the greeting column to properly constrain it.

## 📦 Installation

### End Users

1. **Download**: Get `JUKE-v2.1.0-beta.apk` from [GitHub Releases](https://github.com/rajeet-04/JUKES/releases/tag/v2.1.0-beta)
2. **Install**: Allow installation from unknown sources if prompted
3. **Upgrade**: Your library, playlists, and favorites are all preserved

### Developers / Self-Build

```bash
# Clone
git clone https://github.com/rajeet-04/JUKES.git
cd JUKES

# Configure local.properties
SPOTIFY_CLIENT_ID=your_id
SPOTIFY_CLIENT_SECRET=your_secret
SPOTDOWN_WORKER_URL=https://your-worker.workers.dev/spotdown-key

# Build
./gradlew assembleDebug
```

### System Requirements

- **Minimum**: Android 8.0 (API 26)
- **Recommended**: Android 12.0+ (API 31+)

## ⚠️ Breaking Changes

> None for end users.

For developers self-building: you must add `SPOTDOWN_WORKER_URL` to your `local.properties` file pointing to a Cloudflare Worker that returns the Spotdown API key. Without it, downloads will gracefully fall back to Spotmate only.
