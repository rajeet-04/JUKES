# JUKE v1.0.5-beta Release Notes

## 🚨 Emergency Release Overview

**Release Date:** January 7, 2026  
**Version:** 1.0.5-beta  
**Status:** Beta (Emergency Hotfix)  

This emergency release addresses critical issues with queue synchronization, player stability, and lyrics selection that were affecting user experience after the v1.0.4-beta release.

---

## 🐛 Critical Fixes

### 🔄 Queue Synchronization Fix

**Problem:** When a queue contained duplicate tracks (same song multiple times), the UI would highlight the wrong row after skipping tracks.

**Root Cause:** The app was using `indexOfFirst` to locate the currently playing track by its UUID. With duplicates, this always returned the first occurrence, not the actual playing instance.

**Fix:** The player now uses the exact queue index from ExoPlayer via a new `currentQueueIndexFlow`, ensuring precise state synchronization regardless of duplicates.

---

### ⏩ Rapid Skip Race Condition Fix

**Problem:** Quickly swiping through tracks (using the new swipe gestures) could cause the wrong track's metadata to appear, or tracks to skip unexpectedly.

**Root Cause:** A delayed coroutine (500ms) for updating notification metadata could fire after the user had already moved to a different track, overwriting the new track's info with the old one's.

**Fix:** Added validation check (`player.currentMediaItem?.mediaId == trackId`) before applying delayed metadata updates. Also added a guard clause for `MEDIA_ITEM_TRANSITION_REASON_PLAYLIST_CHANGED` to prevent infinite loops.

---

### 🎵 Lyrics Selection Improvements

**Enhancement:** Improved lyrics matching logic now prioritizes synced lyrics over plain lyrics and uses duration proximity as a tie-breaker for equal-scoring results.

---

## ✨ Features Included (from v1.0.4-beta)

- 👆 **Player Screen Swipe Gestures**: Swipe left/right on album art to skip tracks
- 🌍 **Spotify Region Selector**: Choose your market for personalized search
- ⚡ **Instant Playback**: Stream songs while downloading in background
- 💾 **Queue Persistence**: Streaming tracks saved for cross-restart restoration
- 🛡️ **Deleted Track Safety**: Auto-remove deleted tracks from queue
- ➕ **Create Playlist from Player**: Quick playlist creation in Add dialog
- 🔍 **Search Screen Redesign**: Glassmorphic search bar with filter chips
