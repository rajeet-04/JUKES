# v2.4.2-beta - RELEASE NOTES

Release Date: 2026-10-09

## Overview

v2.4.2-beta makes songs start sooner and the app open faster, lets you open Spotify and YouTube links straight in JUKES, and makes recommendations more varied from session to session. It also hardens playback against audio files that the system deletes.

## 🚀 Features & Enhancements

### Links

- Share a Spotify or YouTube link to JUKES, or tap one in a browser, and it opens in Search.
- Spotify: `open.spotify.com` track, album, artist and playlist links (including `intl-xx` paths), `spotify:` URIs and `spotify.link` short links. They resolve to the exact item.
- YouTube: `music.youtube.com/watch`, `youtube.com/watch` and `youtu.be` links search for the song the video names.
- The bare `open.spotify.com` homepage does not open JUKES.

### Playback

- Progressive playback is on by default: a song played right away starts on the backend's HLS stream while the file downloads. Turn it off in Audio settings. Playlists are not downloaded, and queued songs and downloads still use the full file.

### Recommendations

- Weighted cross-session variety: the same seed song no longer gives the same radio picks every session. Songs you played or skipped recently are less likely to come back, favourites and songs on repeat are exempt, and the offline fallback uses the same logic.

### Startup

- A baseline and startup profile ship in release builds, and the HTTP client, database and stream cache are warmed on a background thread. On the test phone (I2220) the first frame appears in about 155–215 ms, down from about 480 ms.

## 🔧 Fixes & Under the Hood

- Audio files deleted by the system (cache clears, storage cleanup, LRU eviction) are re-downloaded ahead of playback and on a missing-file error instead of being skipped.
- Queue restore no longer waits for the network; unplayable tracks are dropped and stale local paths are cleared.
- The Spotify token response is no longer written to the device log.

## 📦 Build

- Version: `2.4.2-beta` (versionCode 21).
- Database schema v11 (adds `song_exposure`).
- Release build is R8-minified with resource shrinking; `Log.d/v/i/w` calls are stripped.
