# JUKES v2.3.0-beta - Release Notes

## Overview

JUKES v2.3.0-beta focuses on enhancing download reliability through dual-source integration and optimizing storage management with a new LRU streaming cache. This release also decouples streaming playback from the persistent library database to provide a cleaner, more organized user experience.

---

## 🚀 Key Features

### Dual Download Sources (Gamepvz + Spotmate)
We've integrated a secondary download provider, **Gamepvz**, alongside our primary source, **Spotmate**. This significantly increases download success rates through:
- **Automatic Fallback**: If one source fails, the app automatically retries with the other.
- **Load Balancing**: The primary source is randomized to ensure optimal performance across both providers.
- **Duration Validation**: JUKES now verifies audio duration against Spotify metadata; if a duration mismatch is detected (±10% tolerance), the app automatically attempts a re-download from the alternative source.

### LRU Streaming Cache
Streaming music no longer consumes permanent storage unless you explicitly decide to keep it.
- **Fixed-Size Cache**: A dedicated `stream_files/` directory now manages streaming data with a 15-file LRU (Least Recently Used) policy. Older stream files are automatically evicted as you listen to new tracks.
- **Library Decoupling**: Streaming tracks are no longer saved to your local database or library by default. They remain temporary "in-memory-only" items during your session.
- **Promote to Download**: Want to keep a song forever? The "Download" button on the Player Screen or MiniPlayer now seamlessly promotes a temporary stream to a permanent, library-indexed download.

---

## 🔧 Improvements & Bug Fixes

### Database Optimization
- **Library Filtering**: Modified all library and favorites queries to exclude temporary streaming tracks, ensuring your library only contains your curated, downloaded music.
- **Startup Cleanup**: Added a background task that identifies and purges any stale stream entries left over in the database from previous versions of JUKES.

### Player & UI
- **Lyrics Auto-Scroll Fix**: Resolved an issue where the synced lyrics would not automatically scroll to the correct position when toggled on while playback was paused.
- **Improved Playback Cleanup**: Enhanced track-transition logic to effectively clear ExoPlayer caches for temporary streams without requiring database lookups.

---

## 📦 Technical Notes

- `TrackEntity` in the Room database now utilizes the `is_stream` flag more strictly for view-level filtering.
- `MusicService` now handles stream resolution, file downloading, and LRU eviction as a consolidated pipeline.
- `SpotifyApi` refactored to support multiple provider endpoints with unified error handling.
