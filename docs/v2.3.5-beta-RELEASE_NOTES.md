# v2.3.5-beta - RELEASE NOTES

Release Date: 2026-10-04

## Overview

v2.3.5-beta adds Power Tools behind a hidden unlock, queue tools, a smarter Search tab, and fixes for the player's bottom edge and Power Tools scrolling.

## 🚀 Features & Enhancements

### Power Tools (hidden)

- Power Tools sit in Audio Control, locked by default. Tap the version line at the bottom 7 times to unlock them, like Android's developer options. A "Lock Power Tools" button hides them again.
- Advanced: preferred first audio source, repeat threshold (plays per day before a song counts as on repeat), and reset of rejected sources.
- Gestures: optional mini-player double-tap (play/pause) and long-press (favourite).
- Diagnostics and export: library stats, shareable diagnostics report, and a settings/playlists/favourites JSON export (no credentials).

### Queue Tools

- Queue ⋮ menu: shuffle upcoming, sort upcoming A–Z, clear played, save queue as playlist.

### Search

- Tap Search to open the Search screen; tap it again to select the current query and open the keyboard, ready to retype.

## 🔧 Fixes

- Songs that came back as a 30-second preview, or as the wrong length, are now caught: every fetch is checked against the Spotify length, the bad source is skipped and remembered for that song, and the next source is tried. Instant play also checks the file size up front.
- Player: the backdrop now reaches the bottom of the screen, so the screen behind no longer shows through under the controls.
- Power Tools: the list scrolls and clears the floating mini player and tab bar.

## 📦 Build

- Version: `2.3.5-beta` (versionCode 18).
- Release build is R8-minified with resource shrinking; `Log.d/v/i/w` calls are stripped.
