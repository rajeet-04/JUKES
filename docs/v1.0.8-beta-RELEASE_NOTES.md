# JUKE v1.0.8-beta Release Notes

## 🎉 Release Overview

**Release Date:** February 18, 2026
**Version:** 1.0.8-beta
**Status:** Beta Release

JUKE v1.0.8-beta focuses on visual refinement and user experience improvements. This update brings a **complete redesign of the Search Screen** for a more modern aesthetic, introduces a requested **"Most Played" sorting option** for your library, and implements device-specific **Orientation Locking** to ensure a consistent experience across phones and tablets.

---

## 🔑 Key Highlights

### 🔍 Search Screen Redesign

- **Visual Overhaul**: A completely new look featuring a modern, glassmorphic search bar and refined typography.
- **Enhanced Filtering**: New filter chips (All, Tracks, Artists, Playlists) allow for quick and easy result narrowing.
- **Frosted Glass Aesthetics**: Track cards now feature a subtle frosted glass effect, improving readability and visual depth.
- **Accented Library Tracks**: Tracks already in your library are visually distinct, making it easier to spot what you already own.
- **Flat Track Rows**: A cleaner, more compact layout for search results allows user to see more content at a glance.

### 📊 Most Played Sort

- New **"Most Played"** option added to the Library sort menu.
- Sort your downloaded tracks by play count to quickly rediscover your favorite and most-listened-to songs.

### 📱 Portrait Lock (Phones)

- **Device-Specific Locking**: The app logic has been updated to lock orientation to **Portrait** mode on mobile phones for a stable, one-handed experience.
- **Tablet Compatibility**: Tablets retain full **Auto-Rotation** support, allowing for optimal use in both landscape and portrait orientations.
