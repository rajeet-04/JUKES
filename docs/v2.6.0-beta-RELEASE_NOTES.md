# v2.6.0-beta - RELEASE NOTES

Release Date: 2026-10-20

## Overview

v2.6.0-beta makes recommendations match YouTube Music, adds Android Auto browsing, custom playlist order with drag-to-reorder, Play / Shuffle / queue actions on albums, and a synced-lyric line on the player. Spotify credentials no longer ship inside the app, and several lyrics, search and playlist bugs are fixed.

## 🚀 What's new

- **Recommendations like YouTube Music.** The radio is seeded with the song's album-track (audio) upload instead of a stored music-video id, so the same song now gives close to the YouTube Music queue (about 36 of 50 picks in common, up from 16). The backend does the same swap.
- **Personalised radio from your YouTube Music account.** Sign in from Settings; a toggle picks personalised (backend first) or anonymous (direct first) radio.
- **Android Auto.** List-style browse (Recently Played, Favorites, Downloaded), voice and search playback, resume on reconnecting to a car, and cover art.
- **Custom playlist order.** "Custom order" is a new sort inside a playlist. Drag the handle on a song to move it; the other rows slide aside, and the order is saved per playlist and kept across restarts.
- **Queue reordering** now slides the other rows aside as you drag, and the queue changes once on drop.
- **Albums:** Play, Shuffle, Play next and Add to queue, like playlists (queueing places the songs saved offline).
- **Lyric line on the player.** With synced lyrics, the artwork rides up and the current line shows under it, left-aligned and bold; tap it to open the full lyrics.

## 🔧 Fixes

- Search no longer fails when Spotify returns a playlist with a missing owner.
- Restarting the app no longer fetches new recommendations when the restored queue is already full.
- Synced lyrics keep the active line at its reading position (the scroll was cancelled partway by position updates).
- Unsynced lyrics are left-aligned, larger and clear of the close button, and remember their scroll position per song.
- Word-level timestamps inside lyric lines (`[01:37.840]`) no longer show as text.
- The search field no longer takes focus or shows the keyboard while the full player is open.
- Playlists no longer hold the same song twice: import and "save queue as playlist" skip a song already there, and existing repeats are cleaned up once on update.
- Fixed a crash when reordering a playlist that held the same song twice.

## 🔄 Changed

- **Spotify credentials moved off the device.** The Spotify client id and secret now live in a Cloudflare Worker (token cached in KV for about 55 minutes); the app asks the worker for a token. Builds need `SPOTIFY_TOKEN_KEY` in `local.properties` (see `docs/SPOTIFY_SETUP.md`).
- **Lyrics** are fetched from `lrclib.net` directly. The shared worker was being rate-limited (HTTP 429), and it has been removed.

## ⚠️ Upgrade notes

- Older builds fetched lyrics through the removed worker, so lyrics stop loading in them; update to 2.6.0-beta.
- This build contains no Spotify client id or secret: it fetches short-lived access tokens from the Cloudflare Worker and asks again when one expires.

## 📦 Build

- Version: `2.6.0-beta` (versionCode 24).
- Database schema v12 (migration 11→12 removes repeated songs inside playlists and recounts them).
- Needs `SPOTIFY_TOKEN_KEY` at build time; release build is R8-minified with resource shrinking.
