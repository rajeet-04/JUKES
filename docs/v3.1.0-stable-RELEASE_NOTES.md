# v3.1.0-stable - RELEASE NOTES

Release Date: 2026-11-12

Android, macOS, Windows and Linux.

## Overview

v3.1.0-stable is about lyrics: they are sung word by word, found for more songs, and romanized the way people write Punjabi and Urdu.

## 🚀 What's new

- **Word-by-word lyrics.** For songs with word timings, the current line fills in as each word is sung. It works in the full lyrics view on phone and desktop, in the phone mini player, and in the line under the artwork.
- **Lyrics for more songs.** Lyrics come from the JUKES server first, which also finds timed lyrics from YouTube when LRCLIB has none, then from LRCLIB directly.
- **Readable Punjabi romanization.** Gurmukhi lyrics are written the way people type them ("Socha tere baare"), not in academic transliteration.
- **Readable Urdu romanization.** Urdu lyrics get their short vowels back: "dukan", "mumkin" and "mujhe" instead of "dakan", "mamkan" and "majhe". Romanizations saved by older versions are redone once.

## 🔧 Changes

- Phone lyrics card: a darker, even backdrop so every line is readable. Lines already sung sit further back than the lines to come, and lyrics no longer run under the sync and close buttons.
- Opening and closing the lyrics on the phone resizes the card in one motion.
- A song saved with plain lyrics only is checked again for timed lyrics once per app run.

## 🐛 Fixes

- Desktop: "Looking for lyrics..." no longer stays on screen forever, and "Refresh lyrics" uses the new lookup.
- Dragging the phone player closed with lyrics open no longer leaves the artwork floating over the lyrics.
- Changing songs while paused (swiping the artwork, next/previous, or picking from the queue) shows 0:00 right away instead of the last song's time.
- macOS Now Playing shows the JUKE icon instead of a generic one.

## ⚠️ Notes

- The installers are unsigned. On macOS, right-click JUKE.app and choose Open the first time. On Windows, choose "More info" then "Run anyway" when SmartScreen asks.
- Linux: install the `.deb` with `sudo apt install ./JUKE-3.1.0-linux-amd64.deb`.
- The Android APK installs over 3.0.2-beta and keeps your library.
