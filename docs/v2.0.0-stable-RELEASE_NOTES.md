# JUKE v2.0.0-stable Release Notes

## 🎉 Release Overview

**Release Date:** February 20, 2026  
**Version:** 2.0.0-stable  
**Status:** Stable Release  
**Milestone:** First Major Stable Release  

JUKE v2.0.0-stable marks the graduation from beta to production-ready software. This is a comprehensive, feature-complete music streaming application combining Spotify integration, AI-powered recommendations, offline playback, and professional-grade audio controls into a polished, stable experience.

## 📦 Installation & Setup

### For End Users

1. **Download**: Get the latest APK from [GitHub Releases](https://github.com/rajeet-04/JUKES/releases/tag/v2.0.0-stable)
2. **Install**: Open the APK file on your Android device
3. **Grant Permissions**: Allow storage and phone state permissions
4. **Setup Complete**: Launch JUKE and start exploring!

### For Developers

```bash
# Clone repository
git clone https://github.com/rajeet-04/JUKES.git
cd JUKES

# Configure Spotify credentials
echo "SPOTIFY_CLIENT_ID=your_id" > local.properties
echo "SPOTIFY_CLIENT_SECRET=your_secret" >> local.properties

# Build release
./gradlew assembleRelease
./gradlew installRelease
```

### System Requirements

- **Minimum**: Android 8.0 (API 26)
- **Recommended**: Android 12.0+ (API 31+)
- **Storage**: 100MB+ free space
- **Network**: Internet for search/recommendations
