# v2.3.2-beta - RELEASE NOTES

Release Date: 2026-04-27

## Overview

v2.3.2-beta improves lyrics reliability, search responsiveness, and download resilience with queue-aware provider recovery.

## 🚀 Features & Enhancements

### Premium Interactive Media Controls

- Lyrics sync offset range extended from ±5s to ±12s.
- Mini-player smart lyrics fallback:
  - Music-symbol-only lyric lines now fallback to metadata.
  - Adaptive silence-gap threshold (`Median Gap × 2.2`) per song.

### Spotmate Queue-Aware Download Recovery

- Spotmate `/convert` `queued`/`processing` responses now produce typed queue handling with `task_id`.
- Immediate fallback to Gamepvz when Spotmate queues work.
- Deferred recovery via Spotmate task polling (`/tasks/{task_id}`) and `result.download_url`.
- Active in both stream resolution and full `smartDownloadAndIndex` download flow.

### Enhanced Search Experience

- Added low-latency YouTube Music autocomplete suggestions.
- Split search pipeline:
  - Typing: 300ms debounced text suggestions.
  - Submit: full Spotify metadata search.
- Search tab multi-tap logic:
  - Single tap: navigate to Search.
  - Double tap: clear + focus for a new search.
  - Triple tap: focus keyboard without clearing current text.
- Search keyboard polish:
  - Scroll-to-dismiss on downward drag.
  - Delayed `FocusRequester` for reliable keyboard show.
- Search result rows now show duration instead of the previous overflow icon.

### Three-Stage Lyrics Fallback Chain

- Stage 1: LRCLib (existing primary).
- Stage 2: YouTube Music lyrics via Innertube `next` + `browse`.
- Stage 3: YouTube captions via `player` timedtext URL (JSON3 flattened to plain text).
- On-the-fly `ytVideoId` resolution if missing via `RecommenderApi.getBestVideoMatch(...)`.
- YouTube fallbacks run only when LRCLib returns no match.
