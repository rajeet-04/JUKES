# JUKE v1.0.6-beta Release Notes

**Release Date:** January 8, 2026  
**Version:** 1.0.6-beta  
**Status:** Beta Release

JUKE v1.0.6-beta introduces major workflow improvements including **Local Audio Import**, advanced **Batch Operations**, and the new **Skip Silence** feature. This update also delivers critical fixes for queue stability and lyrics reliability, ensuring a seamless listening experience.

## 🔥 Key Highlights

### 🎧 Advanced Playback Control

- **Skip Silence**: Say goodbye to dead air! Automatically detects and skips silent intros and outros, keeping the music flowing continuously.
- **Local Audio Import**: Seamlessly import your own music files (MP3/FLAC) from device storage. Imported tracks get the full JUKE treatment with cover art extraction and metadata indexing.
- **Batch Operations**: Manage your library like a pro. Long-press to multi-select songs and perform batch actions like "Add to Queue", "Play Next", or "Add to Playlist".

### 🛠️ Enhanced Playlist Management

- **Playlist Quick Actions**: Add entire playlists to your queue with a single tap.
- **Inline Renaming**: Rename your local playlists directly from the Library header without navigating away.
- **Smart Queueing**: Adding playlists now respects your sort order and shuffle preferences.

### 🐛 Critical Stability Fixes

- **Queue Deduplication**: Implementing intelligent logic to handle duplicates—new tracks are added, and duplicates are moved to the end, all while keeping your current song playing uninterrupted.
- **Playback Continuity**: Fixed an issue where modifying the queue could cause the current song to restart or skip randomly.
- **Lyrics Reliability**: Updated the lyrics source to a more stable endpoint, ensuring you can always sing along.
- **Queue Synchronization**: Resolved the "ghost song" bug where deleting the currently playing track would desynchronize the player UI.

## 📋 Full Changelog

### Added

- **Local Audio Import**: Import audio files from device storage to `imported_music/` with automatic metadata processing.
- **Batch Operations**: Multi-select functionality in Library for "Add to Queue", "Play Next", and "Add to Playlist".
- **Playlist Management**: "Add to Queue" for full playlists and inline renaming.
- **Skip Silence**: New audio setting to skip silent parts at start/end of tracks.
- **Player Visuals**: Solid black background for tracks with missing album art.
- **Library UI**: Updated header to display active playlist name with quick action buttons.

### Fixed

- **Queue Synchronization**: `MusicViewModel` now observes `queueFlow` for real-time updates when tracks are deleted.
- **Queue Duplication**: Prevents duplication of the currently playing song and intelligently reorders existing duplicates.
- **Playback Continuity**: `setQueue` now preserves exact playback position, preventing restarts during queue updates.
- **LRCLib Source**: Updated lyrics API endpoint for improved reliability.
- **Batch Deletion**: Optimized database operations for faster batch deletions.
- **Compilation**: Fixed `AddToPlaylistDialog` signature preventing `PlayerScreen` crashes.
