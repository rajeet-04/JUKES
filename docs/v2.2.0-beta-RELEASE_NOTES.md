# JUKE v2.2.0-beta Release Notes

## 🚀 Release Overview

**Release Date:** March 18, 2026  
**Version:** 2.2.0-beta  
**Status:** Beta Release  
**Milestone:** Stream Caching & Artist Blacklist  
**Type:** Minor Release

JUKE v2.2.0-beta introduces stream playback caching for instant seeking, artist blacklist functionality for better recommendation control, and several bug fixes improving playback reliability and UI stability.

---

## ✨ New Features

### 1. Stream Playback Caching

**Description:** Integrated ExoPlayer `SimpleCache` with a 256MB LRU disk cache. Seeking back to already-buffered parts of a stream is now instant and doesn't require re-fetching from the network.

**Benefits:**

- Faster seeking in streamed tracks
- Reduced network usage for repeated playback
- Improved user experience for long streams

**Implementation:** Uses `CacheDataSource.Factory` with `DefaultDataSource.Factory` as upstream.

---

### 2. Artist Blacklist UI

**Description:** Added comprehensive artist blacklist functionality to improve recommendation quality by excluding unwanted artists.

**Features:**

- "Blacklist Artist" option in Player Screen more options menu
- Dedicated Blacklist toggle button on the Artist Detail screen
- "Blacklisted Artists" management section in Audio Settings

**Usage:** Blacklisted artists are excluded from recommendations and radio mode.

---

## 🐛 Bug Fixes

### 1. Radio Mode Pause

**Symptom:** Starting radio mode caused a noticeable audio drop.

**Root Cause:** `startRadio` was resetting the entire player instead of surgically trimming the queue.

**Fix:** Optimized to use `removeMediaItem` for queue trimming, preventing audio interruption.

**File:** `PlaybackManager.kt`

---

### 2. Foreground Service Crash

**Symptom:** App crashed with `ForegroundServiceStartNotAllowedException` on Android 12+ when in background.

**Root Cause:** Missing exception handling for background service starts.

**Fix:** Added robust exception handling for the exception.

**File:** `PlaybackService.kt`

---

### 3. Shuffle Logic Bug

**Symptom:** Shuffle toggle failed to correctly update the playback queue or track sequencing.

**Root Cause:** Incorrect queue manipulation in shuffle mode.

**Fix:** Corrected shuffle logic to properly update queue and sequencing.

**File:** `PlaybackManager.kt`

---

### 4. Search Screen Crash

**Symptom:** `IllegalArgumentException` in search results list due to duplicate keys in `LazyColumn`.

**Root Cause:** Duplicate track IDs in search results.

**Fix:** Ensured unique keys in the list.

**File:** `SearchScreen.kt`

---

### 5. Stream Seek Crash

**Symptom:** `MalformedURLException` (no protocol) when playing local files through `CacheDataSource`.

**Root Cause:** Incorrect data source factory for local files.

**Fix:** Used `DefaultDataSource` as upstream factory for local files.

**File:** `PlaybackService.kt`

---
