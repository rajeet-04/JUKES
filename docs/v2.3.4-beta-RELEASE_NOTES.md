# v2.3.4-beta - RELEASE NOTES

Release Date: 2026-10-04

## Overview

v2.3.4-beta rolls up the liquid-glass UI revamp, a reworked audio pipeline, call-aware playback, resumable Spotify playlist imports, and a fix for seeking forward while a track is still streaming.

## 🚀 Features & Enhancements

### UI & Recommendations

- Liquid glass UI revamp with redesigned player, search, and library screens.
- Reserve-based recommendations for steadier queue refills.
- Solid surfaces, compact audio settings, queue status, and playback speed control.

### Audio

- In-pipeline volume and bass boost with stable volume AGC.
- Skip-silence now trims only at track edges.
- Call handling via audio focus and a shared audio controller.

### Smarter Recommendations

- Songs played once earlier today are ranked lower; songs replayed today are treated as on repeat and may return.
- When a YouTube Music radio runs dry, the queue reseeds from the last few songs and recent history instead of falling back to the library.
- A song started from outside the queue builds a fresh queue from its own radio.
- Offline recommendations now use play count, artist affinity, recency, today's plays, variety and artist spreading.

### Wrong Song? Refetch

- New "Wrong song? Refetch" action in the player menu. It fetches the song again from a different source and swaps it into the queue in place.
- The rejected source is remembered per song, so later pulls of that song (re-stream, re-download) put it last.

### Search Tab, Queue and Power Tools

- Tap Search to open the Search screen; tap it again to select the current query and open the keyboard, ready to retype.
- Queue ⋮ menu: shuffle upcoming, sort upcoming A–Z, clear played, save queue as playlist.
- New Power Tools screen (Audio Control → Power Tools): preferred first audio source, repeat threshold, reset rejected sources, mini-player double-tap and long-press shortcuts, library stats, shareable diagnostics, and a settings/playlists/favourites JSON export.

### Spotify Imports

- Playlist imports are resumable: they survive app close and network loss.

## 🔧 Fixes

- Forward seeking after streaming: once the background download completes, the player keeps the local file for the current track. An explicit seek rebuilds the playlist with that local item at the requested position, preserving queue order and play state. If the remote stream is not yet seekable, the seek is deferred until the file is ready and cancelled if the track changes.
- Search and Find Music no longer crash on open (a ViewModel init-order bug).
- Playback no longer errors out when skip-silence or boost processing is idle (audio buffer copy bug).
- Tab navigation: Home, Search and Library always return to their root screen; artist, album and playlist are child screens that are disposed when you switch tabs, from any screen.
- Spotsaver and recommender network hardening.

## 📦 Build

- Version: `2.3.4-beta` (versionCode 17).
- Release build is R8-minified with resource shrinking; `Log.d/v/i/w` calls are stripped.
