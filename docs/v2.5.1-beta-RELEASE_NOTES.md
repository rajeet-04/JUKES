# v2.5.1-beta - RELEASE NOTES

Release Date: 2026-10-12

## Overview

v2.5.1-beta fixes two playback problems found in 2.5.0-beta: a short pause and stutter about three seconds into every song, and notification artwork that stopped following track changes in the background.

## 🔧 Fixes

- Playback no longer pauses and stutters about 3 seconds into a song. A delayed refresh of the notification artwork replaced the playing item and seeked, which flushed the audio buffer on every song. It now does nothing when the artwork and text are already right, and only seeks if a replace really reset the position.
- The notification and lock-screen artwork and title now follow track changes while the app is in the background or the screen is off. Updates were skipped whenever the app wasn't in the foreground, so they only refreshed once playback paused (seen on an OriginOS phone).

## 📦 Build

- Version: `2.5.1-beta` (versionCode 23).
- Database schema unchanged (v11).
- Release build is R8-minified with resource shrinking.
