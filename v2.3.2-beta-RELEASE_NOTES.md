# v2.3.2-beta - RELEASE NOTES

Release Date: 2026-04-27

## Overview

This release focuses on lyrics quality, queue-aware download recovery, and search UX speed. It introduces smarter mini-player lyric fallback behavior, stronger Spotmate queue handling with deferred recovery, and a split autocomplete/search architecture for a more responsive search flow.

## 🚀 Features & Enhancements

### Premium Interactive Media Controls

- **Lyrics Sync Offset Extension:** Increased sync offset range from ±5s to ±12s in `LyricsSyncControls` for severely misaligned lyric tracks.
- **Mini-Player Smart Lyrics Fallback:** Added stale-lyric prevention with two rules:
  - **Music Symbol Filter:** Pure notation lines (♪ ♫ ♬ 𝄞 ♯ ♭ ♮ and similar) now trigger metadata fallback.
  - **Adaptive Gap Threshold:** Per-song fallback threshold computed as `Median Gap × 2.2` for better silence handling across different song tempos.

### Spotmate Queue-Aware Download Recovery

- **Queued Convert Detection:** Spotmate `/convert` responses with `status: queued` or `status: processing` now raise a typed queue exception containing `task_id`.
- **Immediate Fallback Preservation:** JUKE immediately falls back to Gamepvz when Spotmate queues work, avoiding playback/download stalls.
- **Deferred Spotmate Recovery:** If both direct providers fail, JUKE polls `https://spotmate.online/tasks/{task_id}` and downloads from `result.download_url` when status is `finished`.
- **Unified Flow Coverage:** Queue-aware fallback is now active for both instant stream resolution and full `smartDownloadAndIndex` downloads.

### Enhanced Search Experience

- **YouTube Music Autocomplete Integration:** Added lightweight YT Music text suggestions for low-latency typing feedback.
- **Split Search Architecture:**
  - **Typing:** 300ms debounced suggestion fetch through Ktor.
  - **Submission:** Full Spotify metadata search only on Enter or explicit suggestion/recent-search click.
- **Multi-Tap Search Tab Behavior:**
  - **Single Tap:** Navigate to Search.
  - **Double Tap:** Clear query and start a fresh focused search.
  - **Triple Tap:** Focus keyboard without clearing the current query.
- **Precision Keyboard Management:**
  - **Scroll-to-Dismiss:** Dragging search results down by more than 5px dismisses the keyboard.
  - **Programmatic Focus:** 100ms delayed `FocusRequester` calls improve reliability on navigation transitions.
- **Duration-Aware Search Rows:** Replaced the unused 3-dots icon with track duration text for consistency with library row formatting.

### Three-Stage Lyrics Fallback Chain

Expanded lyric coverage by adding two YouTube-backed fallback sources after LRCLib:

- **Stage 1 - LRCLib (Primary):** Existing exact + individual-artist matching with ranking by validation score, synced availability, and duration proximity.
- **Stage 2 - YouTube Music Lyrics:** Uses Innertube `next` + `browse` flow when LRCLib misses.
- **Stage 3 - YouTube Captions:** Uses YouTube `player` response timedtext URL (JSON3) and flattens captions to plain text.
- **On-the-Fly Video ID Resolution:** Resolves missing `ytVideoId` inline via `RecommenderApi.getBestVideoMatch("$title $artist")` before Stage 2/3 requests.
- **No LRCLib Regression:** YouTube fallback calls are only made when LRCLib returns `null`, preserving performance for already-covered tracks.

## 🔧 Stability & Behavior Improvements

- Prevents stale or instrumentation-only lyric lines from sticking in mini-player surfaces.
- Improves reliability when Spotmate pipelines are backlogged.
- Reduces search latency and accidental heavy API calls during text entry.
